Dúvidas

O essencial, direto ao ponto.

O que acontece se eu falhar um dia?

Marque “Mínimo” para manter o hábito vivo ou “Não fiz” sem culpa. O Arco mostra a consistência do período, não pune um dia isolado.

Quem decide quando subir de nível?

Você. O app sugere quando a regra do hábito é cumprida (por exemplo, 80% em 14 dias), mas a decisão é sempre manual.

Preciso estar online?

Não para o check-in. Ele é guardado e enviado quando a conexão voltar. As demais ações precisam de rede.

Posso usar fora do app?

Sim. Toda funcionalidade está disponível pela API com chave própria. O servidor MCP, para usar com assistentes de IA, é exclusivo do plano Pro.

Os lembretes funcionam no iPhone?

Só depois de instalar o Arco na tela de início (Compartilhar, Adicionar à Tela de Início). No Safari comum o iOS não entrega notificações push.
