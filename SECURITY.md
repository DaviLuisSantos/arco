# Política de segurança

## Como reportar uma vulnerabilidade

Use o recurso de relato privado do GitHub: abra a aba **Security** do repositório e clique em **Report a vulnerability**.

Não reporte vulnerabilidades por issue pública, pull request ou discussão, pois isso expõe o problema antes da correção.

Inclua, se possível, a descrição do problema, os passos para reproduzir e o impacto estimado. Você receberá uma resposta pelo próprio relato.
